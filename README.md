# Продавателникът на Митко - Професионален Уеб Сайт

## 📱 За сайта

Това е премиумен, пълнофункционален уеб сайт за продажба на уеб услуги на булгарски език. Сайтът е разработен с фокус на качество, модерен дизайн и плавни анимации.

## ✨ Основни характеристики

- **Премиум дизайн** - Модерен, тъмен дизайн с градиентни елементи
- **Пълна анимация** - Всички елементи имат гладки преходи и анимации
- **Отзивчив дизайн** - Работи идеално на мобилни, таблети и десктопи
- **SEO оптимизиран** - Включени са необходимите мета тагове
- **Бързо зареждане** - Оптимизирани изображения и CSS
- **Достъпност** - Подходящ за всички устройства и браузъри

## 🚀 Как да използвате

### Локално

1. Клонирайте или изтеглете хранилището
2. Отворете `index.html` в браузъра си
3. Наслаждавайте се на сайта!

### GitHub Pages

1. Качете всички файлове в GitHub хранилище
2. Отидете на Settings → Pages
3. Изберете `main` branch като източник
4. Сайтът ще бъде достъпен на `https://yourusername.github.io/repo-name`

### cPanel

1. Свържете се към cPanel управления панел
2. Отворете File Manager
3. Качете всички файлове в `public_html` папката
4. Сайтът ще бъде достъпен на вашия домейн

### Vercel

1. Свързате GitHub хранилище с Vercel
2. Vercel автоматично ще деплой сайта
3. Сайтът ще бъде достъпен на Vercel поддомейн

## 🎨 Персонализация

### Промяна на цветове

Отворете `style.css` и намерете `:root` селектор на начало:

```css
:root {
    --primary: #06b6d4;
    --primary-dark: #0891b2;
    --accent: #fbbf24;
    /* ... останалите цветове ... */
}
```

Променете стойностите на цветовете според ваши желания.

### Промяна на текст

Отворете `index.html` и намерете текста, който искате да промените:
- Заголовки в `<h1>`, `<h2>`, `<h3>` тагове
- Параграфи в `<p>` тагове
- Навигационни връзки в `<a>` тагове

### Добавяне на нови секции

Скопирайте кода на съществуваща секция и модифицирайте го според ваши нужди.

## 📧 Контакт форма

Контакт формата е готова за употреба, но не изпраща имейлове по подразумеване.

За да активирате имейл функционалност:

1. **Използвайте сервис като Formspree:**
   - Отидете на formspree.io
   - Създайте нов проект
   - Получете хост URL
   - Променете `action` атрибута на формата:
   ```html
   <form action="https://formspree.io/f/YOUR_FORM_ID" method="POST">
   ```

2. **Или използвайте EmailJS:**
   - Регистрирайте се на emailjs.com
   - Следвайте документацията
   - Добавете JavaScript кода за изпращане

## 🐛 Отстраняване на грешки

### Анимациите не работят
- Проверете дали JavaScript е включен
- Очистете браузъра кеш (Ctrl+Shift+Delete)

### Мобилното меню не работи
- Проверете дали `script.js` е правилно зареден
- Отворете браузъра консола (F12) и проверете за грешки

### Контакт форма не изпраща
- Проверете дали имайте сет на `form action` атрибут
- Отворете консолата и проверете за грешки
